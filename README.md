### 🚀 Featured Projects

- **🤖 Autonomous Manhole/Sewage Cleaning Robot** — Final year B.Tech project. ESP32-WROOM-32 + ESP32-CAM, OpenCV HSV-based detection, servo gripper, L298N motor driver, moisture sensor, suction pump.
- **🧺 SmartBasket** — ESP32-based smart waste basket with Blynk app control, HC-SR04 ultrasonic sensing, servo compression, buzzer/LED alerts, FreeRTOS deep-sleep firmware, and MQTT telemetry.

- **🔢 SGPA Calculator** — A React app implementing the full KTU 2019 grading scheme.
